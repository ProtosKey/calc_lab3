# Интегральный калькулятор

Десктопное приложение для численного интегрирования функций.

## Возможности приложения
- **Численное решение:** Методы прямоугольников (левые, правые, средние), Трапеций и Симпсона
- **Интерактивный графический интерфейс:** Визуализация формул в реальном времени
- **Валидация:** Строгий контроль ввода данных и обработка математических исключений

## Используемые технологии
- **Kotlin 1.9**
- **Compose Multiplatform** 
- **BigDecimal** (для точных вычислений)
- **JLatexMath** (для рендеринга формул)

## 📂 Структура проекта
- `core/` - алгоритмы, интегралы, граница и точность
- `presentation/` — логика управления состоянием
- `view/` — графические компоненты и экран приложения
